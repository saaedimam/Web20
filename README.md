
# 🏭 Kattali Textile Ltd. - Corporate Website

[![Deploy Status](https://img.shields.io/badge/Deploy-Replit-FF5722)](https://replit.com)
[![Status](https://img.shields.io/badge/Status-Production-success)](https://ktl-corporate.vercel.app)

Modern, responsive corporate website for Kattali Textile Ltd. (KTL) - Leading sustainable B2B textile manufacturing in Bangladesh.

## 🌟 Features

### Current Features ✅
- **Responsive Design** - Mobile-first approach with modern UI/UX
- **Stock Dashboard** - Real-time KTL stock data (KTLBD)
- **PWA Ready** - Service worker, manifest, offline support
- **SEO Optimized** - Meta tags, sitemap, structured data
- **Corporate Pages** - About, Sustainability, Certifications, Contact
- **Modern Animations** - Smooth scrolling, micro-interactions
- **Mobile Navigation** - 6-dot menu with smooth dropdown

### Planned Features 🚧
1. **Interactive Product Catalog** - Filterable fabric samples
2. **B2B Client Portal** - Order tracking, custom pricing
3. **Live Chat Integration** - WhatsApp Business API
4. **Multilingual Support** - Bengali, English, Arabic
5. **Sustainability Dashboard** - Real-time environmental metrics
6. **News/Blog CMS** - Industry insights and updates
7. **Quote Request System** - Custom fabric calculator

## 🛠 Tech Stack

- **Frontend:** Vanilla HTML5, CSS3, JavaScript ES6+
- **Styling:** CSS Custom Properties, CSS Grid, Flexbox
- **Build:** http-server for development
- **Deployment:** Replit + Vercel
- **PWA:** Service Worker, Web Manifest
- **Performance:** Lazy loading, code splitting

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/saaedimam/Web20.git
cd Web20

# Start development server
npx http-server ./ --port 5000 --host 0.0.0.0

# Open http://localhost:5000
```

## 🎨 Design System

### Colors
- **Primary:** `#0f172a` (Corporate Navy)
- **Secondary:** `#1e293b` (Dark Slate)
- **Accent:** `#3b82f6` (Corporate Blue)
- **Success:** `#059669` (Textile Green)
- **Warning:** `#f59e0b` (Gold)

### Typography
- **Font:** Inter (Google Fonts)
- **Scale:** Modular scale for consistent hierarchy
- **Weights:** 300, 400, 500, 600, 700, 800

### Components
- **Buttons:** 4 variants (primary, secondary, outline, ghost)
- **Cards:** Hover effects with gradient accents
- **Navigation:** Sticky header with smooth hide/show

## 🔧 Development

### Scripts
```bash
# Development server
npm run dev

# Build for production  
npm run build

# Lint and format
npm run lint
npm run format
```

### Environment Setup
1. Clone repository
2. Install http-server: `npm install -g http-server`
3. Start server: `http-server ./ --port 5000`
4. Open browser to `http://localhost:5000`

## 🚀 Deployment

### Replit Deployment
1. Fork project on Replit
2. Click "Deploy" button
3. Choose "Reserved VM Deployment"
4. Custom domain available

### Manual Deployment
1. Build static files
2. Upload to hosting provider
3. Configure domain and SSL
4. Set up CDN for images
